# Модуль `app_asg`

Группа автомасштабирования. Отвечает на вопрос **сколько инстансов и где**, тогда как
launch template из юнита `app/ec2` отвечает на **какая машина**.

Обёртка над `terraform-aws-modules/autoscaling/aws` с выключенным созданием шаблона:
шаблон приходит готовым через `dependency` из соседнего юнита.

## Входы

| Имя | Тип | По умолчанию | Описание |
|---|---|---|---|
| `name` | `string` | — | базовое имя, например `week3-dev` |
| `launch_template_id` | `string` | — | приходит из юнита `ec2` |
| `launch_template_version` | `string` | `$Latest` | новые инстансы берут свежую версию |
| `vpc_zone_identifier` | `list(string)` | — | подсети группы |
| `target_group_arn` | `string` | — | target group балансировщика |
| `min_size` / `max_size` / `desired_capacity` | `number` | — | границы группы |
| `cpu_target_value` | `number` | `40` | цель target tracking |
| `health_check_grace_period` | `number` | `180` | запас на загрузку ОС, установку Docker и скачивание образа |
| `tags` | `map(string)` | `{}` | дополнительные теги |

## Выходы

`autoscaling_group_name`, `autoscaling_group_arn`, `autoscaling_policy_arns`.

## Три места, где ошибаются

**`traffic_source_attachments`, а не `target_group_arns`.** В версиях модуля до 8.x привязка
к балансировщику называлась `target_group_arns`. В 9.x аргумент **удалён**.

**`health_check_type = "ELB"`, а не дефолтный `EC2`.** При `EC2` группа считает здоровой
машину с упавшим контейнером: виртуалка-то запущена. При `ELB` она доверяет проверкам
балансировщика.

**`enabled_metrics` нужно задавать явно.** По умолчанию список пустой, и график «сколько
инстансов в строю» окажется пустым ровно тогда, когда понадобится для отчёта.

## Про grace period и блокирующее приложение

180 секунд — не запас «на всякий случай», а измеренная величина: установка Docker
и скачивание образа занимают 1-2 минуты. Отдельно стоит помнить, что `/tools/load`
в этом приложении блокирует event loop Node.js целиком, поэтому под нагрузкой инстанс
перестаёт отвечать на health check, оставаясь живым. Пороги проверки в модуле `alb`
смягчены именно под это.
